Notes · applying to Network Topology.html
Where to edit
Replace the <symbol id="i-router"> block at line 599 of Network Topology.html. The P-router and PE-router both use i-router — you can add a separate i-pe-router symbol and update classifyNode() to assign it.
Node card layout
The node card HTML lives in renderNodes() around line 912. The CSS class .node-card controls the card shape. Choose the card variant above and the combined icon+card style is what will be applied.
