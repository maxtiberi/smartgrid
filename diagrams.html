Concurrency & Reliability Controls
semaphore(2)
Max 2 nodes fetching simultaneously — limits total gRPC connections to Nokia TIMOS
_isisSem(2)
Global IS-IS adjacency semaphore — only 2 heavy interface/adjacency GETs in-flight across all nodes
_nodeRefreshing
Boolean lock prevents concurrent refresh cycles — eliminates race on prevIsisIfaces baseline
IS-IS merge
Pre-cycle snapshot — empty query result falls back to last known adjacency list, never overwrites good data

Dashboard Feature Map
Four interconnected panels — power grid simulation, MPLS live topology, deep telemetry, and IEC 61850 teleprotection

Power Grid Simulation

4 generation sources — Nuclear α/β (1.2 GW each), Solar (800 MW ±5% noise), Wind (400 MW ±7.5% noise) with adjustable sliders
Animated energy flow — step-up transformer → 4 feeders F1–F4 → secondary substations → 2.8 GW city demand
DER node — PV + BESS (350 kW) with bidirectional flow on Feeder F4
MPLS coupling — each unreachable access node removes 25% from city supply, linking network faults to grid impact
Statistics rings — circular progress indicators for 7 routers, 2 RTUs, overall health

MPLS Live Topology

SVG topology panel — 7 nodes, 10 links, role-differentiated styles (core/aggregation/access/RTU)
Link fault detection — gNMI port state polling every 15 s; any port reporting down turns link red with blinking animation
Clickable node popups — dc1, dc2, ACCESS1-1: port LED grid, interfaces+counters, IS-IS adjacencies, SR prefix/adj SIDs
SR-TE LSP overlay — primary path solid purple, standby path dim dashed; active path switches on failover
Security toggle — AES-256 / open-lock packet animations on topology links

Telemetry Detail Page

Interface status cards — one per router; SVG donut ring showing active%, LED port grid, scrollable interface list with IPv4
IS-IS adjacency table — one row per adjacency; node, interface, level, neighbour SysID, neighbour IP, uptime (d/h/m)
Route table — active routes per node by protocol (isis, local, static, bgp) from SR OS route-table statistics path
LSP detail card — oper-state, active path, path type badge, primary/secondary path table with individual oper-states
SSE live push — page subscribes to /api/events; all four sections update on every cache broadcast

IEC 61850 TPT Panel

Industrial infographic — 400 kV HV line, transformers, 19" rack RTU illustrations, MPLS-TP communication link
GOOSE pulse animation — bidirectional packet pulses ACCESS1-1 ↔ ACCESS1-3, halted on comm fault
Link fault indicator — port 1/1/c3/1 on ACCESS1-1 monitored every 10 s; if down → red LINK FAULT badge
Trip / Clear controls — proxied to both RTU HTTP APIs simultaneously; badge switches CLOSED↔OPEN
V/I telemetry — voltage sags to 0.35 p.u., current spikes to 2.8 p.u. on trip event (simulated by tpt-daemon.py)
